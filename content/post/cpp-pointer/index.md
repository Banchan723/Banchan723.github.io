## 이 글에서 이해할 것

포인터가 "주소"를 담는다는 것, `*p`로 그 주소 안의 값을 읽고 쓴다는 것, 포인터가 가리키는 대상을 바꿔도 원래 변수는 그대로라는 것.

## 읽기 전 최소 배경

변수에 값을 넣고 꺼내는 것(`int a = 10;`)과 `cout` 출력 정도는 안다고 가정한다.

## 확인한 증거

```cpp
int a = 10;
int b = 20;
int* p = &a;
cout << *p << endl;   // 10
p = &b;               // p가 b를 가리키게 바꿈
*p = 99;              // 지금 가리키는 걸 99로
cout << a << endl;    // 10
cout << b << endl;    // 99
```

직접 돌린 출력: `10` / `10` / `99`. `*p = 99`를 했는데도 `a`가 10 그대로 나온 게 핵심이다.

## 그래서 이렇게 이해했다

`int* p = &a`는 "p에 a의 주소를 넣는다"는 뜻이다. p는 주소를 들고 있고, `*p`로 그 주소 안의 값을 읽거나 바꾼다. `p = &b`로 가리키는 대상이 바뀌면 a는 그대로 살아있고 p와 a의 연결만 끊긴다. 그래서 `*p = 99`는 지금 가리키는 b만 바꾸고 a(10)는 건드리지 않는다.

나만의 규칙: 포인터가 가리키는 대상을 바꿔도 원래 변수는 사라지지 않는다 — 연결만 끊길 뿐 변수는 제자리에 그대로 있다.

## 다른 예시에 적용해보기

```cpp
int x = 5;
int* q = &x;
*q = *q + 10;   // 오른쪽 *q: x 읽기(5) -> +10 -> 왼쪽 *q: x에 써넣기
cout << x << endl;   // 15
```

직접 돌린 출력: `15`. `*q = *q + 10`은 수학 등식이 아니라 "오른쪽을 계산해서 왼쪽 자리에 넣어라"는 명령이다. 같은 `*q`라도 오른쪽은 읽기, 왼쪽은 쓰기다.
