## 개념 정의

포인터는 다른 변수의 **주소**를 담는 변수다. `*`(역참조)로 그 주소가 가리키는 값을 읽거나 쓴다.

- **이 글에서 다루는 것**: 포인터 선언과 주소(`&`), 역참조(`*`)로 읽기·쓰기, 가리키는 대상 바꾸기, 좌변·우변 `*p`의 차이.
- **이 글 밖(다음 토픽)**: 함수 매개변수로 원본 바꾸기, 포인터 산술, 배열과 포인터, 이중 포인터, 스마트포인터.

## 왜 필요한가

변수를 직접 다루는 대신 그 변수의 **자리(주소)를 들고** 값을 간접적으로 읽고 쓰기 위해서다. 주소를 들고 있으면 지금 가리키는 대상을 다른 변수로 바꿀 수도 있고, 그 자리의 값을 고칠 수도 있다.

## 문법과 동작

- `int* p = &a;` — `&a`는 a의 주소다. 그 주소를 p에 넣는다. p는 "주소를 담는 변수".
- `*p` — p가 가리키는 주소 안의 값. 읽기에도 쓰기에도 쓴다.
- `p = &b;` — p가 가리키는 **대상 자체를 갈아끼운다**(값이 아니라 주소를 바꿈).

## 직접 확인한 예제

```cpp
int a = 10;
int b = 20;
int* p = &a;
cout << *p << endl;   // 10
p = &b;               // p가 b를 가리키게 바꿈
*p = 99;              // 지금 가리키는 걸 99로
cout << a << endl;    // 10
cout << b << endl;    // 99
```

직접 돌린 출력: `10` / `10` / `99`. `*p = 99`를 했는데도 `a`가 10 그대로인 게 핵심이다 — `p = &b` 시점에 p는 더 이상 a를 가리키지 않는다.

```cpp
int x = 5;
int* q = &x;
*q = *q + 10;   // 오른쪽 *q: x 읽기(5) -> +10 -> 왼쪽 *q: x에 써넣기
cout << x << endl;   // 15
```

직접 돌린 출력: `15`. `*q = *q + 10`은 수학 등식이 아니라 "오른쪽을 계산해서 왼쪽 자리에 넣어라"는 명령이다. 같은 `*q`라도 오른쪽은 읽기, 왼쪽은 쓰기다.

## 흔한 실수와 오해

**오해**: `*p = 99`는 처음 가리켰던 변수(a)를 바꾼다.

```cpp
int* p = &a;
p = &b;      // 대상이 b로 바뀜
*p = 99;     // a가 바뀔 거라 착각하기 쉬움
```

**왜 틀렸나**: `p = &b` 시점에 p와 a의 연결은 끊겼다. `*p`는 지금 가리키는 b를 바꾼다. a는 제자리에 10 그대로 있다. 포인터가 가리키는 대상을 바꿔도 원래 변수는 사라지지 않는다 — 연결만 끊길 뿐이다.

## 관련 토픽과 다음 경계

- **다룬 것**: 주소(`&`)·역참조(`*`)·가리키는 대상 변경·좌변과 우변 `*p`의 차이.
- **아직 모르는 것**: 포인터를 함수의 매개변수로 넘기면 함수 안에서 원본을 바꿀 수 있는지.
- **다음 토픽**: 참조(`&`) — 별명으로 같은 일을 더 안전하게.

```yaml
verification:
  checked_claims:

    - { claim: "좌변 *q는 쓰기, 우변 *q는 읽기", evidence: "예제2 출력 15" }
unknowns:
  - "포인터를 함수 매개변수로 넘겨 함수 안에서 원본 변경 (다음 토픽)"
```
